  This app uses multiple features that employ components from react. The first feature is the list of users which is fetch from a json API. The second feature if the user search which filters out users from the API. The third is a list of posts which is grabbed from the second API. The fourth is a favorite functionality which allows the user to save their favorite user. The final feature and component is the App.js file which brings all of these components together and displays them through props.
